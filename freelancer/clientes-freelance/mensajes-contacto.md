# Textos de contacto — captación de clientes freelance

Todos parten del mismo mensaje base que ya escribió Berenice (mantiene su voz real,
no una genérica). Se adaptan por canal, no se reinventan. Ninguno menciona clientes,
tecnologías o experiencia que no estén verificados en
`FREELANCER_MASTER_CONTEXT.md`.

**Antes de mandar cualquiera de estos:** completar el link de portfolio/demo que
corresponda según lo que pregunte el cliente (ver tabla del punto 4 en
`ESTRATEGIA-48HS.md`). No pegar el mismo texto genérico sin adaptarlo un mínimo a
quién lo recibe.

---

## 5. Texto base (el que ya escribió Berenice — usar tal cual para contacto directo)

```
Hola! ¿Cómo estás?

Soy Berenice, desarrolladora web de Rosario.

Estoy tomando algunos trabajos puntuales de desarrollo y mantenimiento, especialmente
para resolver problemas concretos en webs y sistemas existentes.

Trabajo con Python/Django, React, Node, APIs, bases de datos y servidores.

Si tienen alguna web o sistema que esté dando problemas, haya quedado a medias o
necesite alguna mejora, puedo revisarlo y decirte rápidamente qué habría que hacer y
cuánto costaría.

También puedo tomar trabajos chicos y urgentes.

Si querés, pasame la web o contame qué problema tienen y lo reviso.
```

## 6. WhatsApp

Igual al texto base — ya está pensado para ese formato (corto, directo, sin
formalismo de más). Si es alguien que ya la conoce personalmente, sacar el
"¿Cómo estás?" inicial y arrancar directo:

```
Hola [nombre]! Te escribo porque estoy tomando algunos trabajos de desarrollo web —
arreglos, mantenimiento, mejoras chicas.

Si tenés alguna web o sistema que ande fallando o que quedó a medias, contame y lo
reviso — te digo rápido qué se puede hacer y cuánto saldría.
```

## 7. Instagram / DM

Más corto todavía — en DM se lee de un vistazo o se ignora:

```
Hola! Vi tu [perfil/cuenta] y quería comentarte: hago arreglos y mejoras de webs y
sistemas — Django, React, Node.

¿Tenés algo que ande fallando o medio abandonado? Lo reviso gratis y te cuento qué
se puede hacer.
```

## 8. LinkedIn

Registro un poco más profesional — acá sí vale mencionar los sistemas reales en
producción, porque el público de LinkedIn responde mejor a evidencia concreta que a
un mensaje casual:

**Para mensaje directo (1er/2do grado):**
```
Hola [nombre], ¿cómo estás?

Soy Berenice, Full Stack Developer (Django + React/Node) en Rosario. Desarrollo y
mantengo sistemas en producción real — dos de mis proyectos se usan hoy en un
hospital (Hospital Eva Perón).

Estoy tomando trabajos puntuales de mantenimiento y mejora de sistemas/webs
existentes — bugs, integraciones, deploy, optimización. Si conocés a alguien (o si
vos mismo/a) tiene algo que necesite una mano, encantada de charlarlo.
```

**Para post público (si prefiere publicar en vez de escribir uno por uno):**
```
Estoy tomando trabajos puntuales de desarrollo — arreglos, mantenimiento y mejoras
sobre webs/sistemas ya existentes (Django, React, Node, APIs, bases de datos,
deploy en servidor propio).

Si tu web o sistema tiene algo que anda mal, quedó a medias, o simplemente necesita
una revisión, escribime — reviso y te cuento qué se puede hacer y cuánto costaría,
sin compromiso.
```

## 9. Workana (plantilla de propuesta — completar por cada aviso puntual)

Workana pide postularse a un aviso concreto, así que esto es una plantilla, no un
texto para pegar igual siempre. Reemplazar lo que está entre `[ ]`:

```
Hola! Vi tu publicación sobre [resumen del problema que describe el cliente en 1
línea, usando sus propias palabras].

Soy Berenice, Full Stack Developer (Django + React/Node), con sistemas propios en
producción real — no solo proyectos de práctica (dos de ellos se usan hoy en un
hospital). Trabajo con testing automatizado en profundidad, así que un arreglo no
rompe algo más sin que me dé cuenta.

Para este caso puntual: [1-2 líneas concretas de cómo lo encararías vos, específico
al problema que planteó — no genérico].

Puedo empezar por revisar el estado actual y confirmarte en poco tiempo qué hace
falta y cuánto sale, antes de comprometernos a nada más grande.

Portfolio: https://ailonline.com.ar (VI y librook, con demo navegable sin cuenta)
```

**Nota sobre Workana:** buscar específicamente avisos de "arreglo puntual",
"mantenimiento" o "mejora chica" — no competir por proyectos grandes desde cero
contra freelancers con más track record ahí. Coincide con lo que la oferta real
puede entregar rápido.
