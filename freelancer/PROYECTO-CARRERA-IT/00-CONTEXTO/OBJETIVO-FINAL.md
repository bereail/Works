# OBJETIVO FINAL

Transformar el GitHub de Berenice en un perfil que pueda ser revisado por recruiters,
desarrolladores senior, tech leads y CTOs, y que transmita:

> "Esta persona sabe desarrollar software, sabe documentar lo que hace, entiende buenas
> prácticas y puede incorporarse a un equipo profesional."

## Criterio de "terminado" para un repositorio

NO alcanza con que compile, funcione, tenga README o tenga tests. Un repositorio está
terminado cuando puede mostrarse públicamente como parte del portfolio profesional y se
puede decir con honestidad:

> "Este repositorio está listo para ser visto por un recruiter y un desarrollador senior."

## Meta cuantitativa de esta etapa

Tener entre **3 y 5 proyectos** de nivel A, impecables, para mostrar con orgullo en la
búsqueda laboral. El resto del GitHub debe estar, como mínimo, ordenado y sin banderas rojas.
